# dsh-image-compare

[English](README.en.md)

**一次对比多张图片**的 DeepSeek Harness 插件。

Harness 内置的 `read_image` 一次只能把**一张**图放进对话窗口——想看"改前 vs 改后"、"这五个方案的截图"，只能一张张来回翻。这个插件加了工具 `view_images`：**一次打开一整组图，铺成可翻页的对比视图**，同页并排、逐张缩放、任意拖动排序。

关键一点：**图片是给人看的，字节不进模型上下文**。开 20 张 2MB 的图，对话里只多一行字。

## 主要功能

**对比多张图**（核心）

- **一页并排 1/2/3/4/6 张**（默认 2 张）——两张图真正左右/上下对照，而不是来回滚动。
- **整组同步**：把当前这张的**缩放和显示位置**一起应用到全部图片，于是每张都显示"同一处内容"——对比细节时这才是真正对齐。
- **任意排序**：拖动底部缩略图即可调整顺序，方便把要对照的两张放到一起。

**看图**

- **每张独立缩放**：点选某张，缩放行只作用于它，范围 0.1x–8x；双击在放大与适应之间切换。
- **中键拖动平移**：位移与鼠标一比一，松手即停；按住 `Shift` 则整组一起平移。
- **上下 / 左右翻页**：滚轮、方向键、上一页/下一页按钮都能翻，滚轮一次正好翻一页。
- **缩略图条**：点任意一张跳到它所在的页。

**取图**

- **面板内浏览工作区**：上级目录、路径框、刷新、勾选多张后「打开」。本地会话列本地、SSH 会话列远程。
- **路径读不出会说明原因**：越界 / 不是图片 / 找不到，分别给出提示，而不是一个裂图。

## 安装

插件是标准的 DSH profile 组合包，包内自带全部声明，**不需要手写任何配置文件**。

### 插件页面（推荐）

1. 打开 Web 界面，左侧栏点 **插件**；
2. 点 **添加插件**，粘贴以下任一种：
   - `github:ChordXD/dsh-image-compare`
   - 本地目录的**绝对路径**
   - npm 包名（发布后）
3. 确认它处于**启用**状态；
4. **重启 DeepSeek Harness**。

### 命令行

```sh
dsh plugin --profile web add github:ChordXD/dsh-image-compare
```

从 GitHub 安装会执行构建脚本，pnpm 默认拦截；dsh 会打印需要加进该 profile `pnpm-workspace.yaml` 的 `allowBuilds` 键名，加好后重跑即可。想锁定版本就带上 commit：`github:ChordXD/dsh-image-compare#<sha>`。

### 卸载

在插件页面移除，或 `dsh plugin --profile web remove dsh-image-compare`，然后重启。

> 环境：DeepSeek Harness 0.2.0-rc.2 及以上（Web 界面 / 桌面版）。**不需要安装任何依赖**——宿主半边用 profile 提供的服务，客户端只用 shell 预载的 `react`。

## 使用

直接让模型对比看图即可，它会调用：

```
view_images(
  images    = [{ path: "shots/before.png", label: "改前" },
               { path: "shots/after.png",  label: "改后" }],
  layout    = "vertical",   # 或 "horizontal"，默认 vertical
  page_size = 2,            # 1/2/3/4/6，默认 2
  title     = "首页改版对比",
)
```

- `images`：图片路径列表，相对路径按会话工作目录解析；每项是 `{ path, label? }`。一次最多 60 张。
- 对话里出现卡片后，点「**右侧栏**」把它发布到右栏面板（推荐），或点「**全屏**」看浮层。

不知道有哪些图时，让模型用 `browse_images(path?, recursive?, max_depth?)` 列出目录，省略 `path` 即列出工作区根。

## 操作

鼠标（图片区内）：

| 手势 | 作用 |
| --- | --- |
| 左键点击 | 选中这张图 |
| `Ctrl` / `Cmd` + 滚轮 | 缩放指针下那张（以指针为锚点） |
| `Ctrl` / `Cmd` + `Shift` + 滚轮 | 把当前那张的缩放与位置**同步到整组** |
| 中键拖动 | 平移这张放大的区域 |
| `Shift` + 中键拖动 | 整组一起平移 |
| 滚轮（无修饰键） | 翻页，一格一页 |
| 双击图片 | 放大 ↔ 回到适应 |
| 拖动缩略图 | 调整图片顺序 |

缩放行（图片区上方）：百分比读数、`−`、`+`、`适应`、`100%`、`移动`、`同步全部`、`重置`、`⚙`（设置）。

键盘：

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 上一页 / 下一页（上下翻页时） |
| `←` `→` / `PageUp` `PageDown` | 上一页 / 下一页（两种翻页方向都可） |
| `Home` / `End` | 第一页 / 最后一页 |
| `+` / `-` | 放大 / 缩小选中的那张（「移动」模式下作用于整组） |
| `0` | 全部回到默认缩放 |
| `V` | 切换上下 / 左右翻页 |
| `2`–`6` | 每页 1 / 2 / 3 / 4 / 6 张 |
| `F` | 显示 / 隐藏缩略图条 |
| `Esc` | 关闭全屏浮层 |

齿轮里可以设置：默认缩放、每页张数、是否默认展开缩略图条、查看器字号、单张图片最小高度。

## 与其他看图插件的区别

| | 看图对象 | 一次看几张 | 图片是否进模型上下文 |
| --- | --- | --- | --- |
| DSH 内置 `read_image` | 模型 | 1 张 | 是 |
| 增强内置查看器的插件 | 已渲染的图 | 1 张为主 | 否 |
| 视觉模型桥接类插件 | **模型** | 多张 | **是**（消耗视觉额度） |
| **本插件** | **人眼** | **一组，并排可翻页** | **否** |

一句话：它是**给人做多图对比**的工具，不是给模型读图的通道。
